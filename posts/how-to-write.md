# 如何写一篇新文章

本博客的写作体验被刻意设计得**极简** —— 你只需要和 Markdown 文件打交道。

## 三步发布

### 第一步：新建文件

在 `posts/` 目录下新建一个 `.md` 文件，文件名建议用英文（它也是文章的网址）：

```
posts/my-new-post.md
```

### 第二步：写头部信息

文件开头添加一段头部信息（frontmatter）：

```markdown
---
title: 文章标题
date: 2026-08-20
tags: [技术, 教程]
excerpt: 一句话摘要，会显示在首页卡片上。
---

正文从这里开始……
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| title | 建议 | 文章标题 |
| date | 建议 | 发布日期，首页按它排序 |
| tags | 可选 | 标签数组，自动生成筛选器 |
| excerpt | 可选 | 摘要；不写则自动截取正文 |

### 第三步：推送

```bash
git add posts/my-new-post.md
git commit -m "发布新文章"
git push
```

推送后 1 分钟内，文章会自动出现在首页 —— **无需修改任何其他文件**。

## 支持的 Markdown 能力

所有常用语法均支持：

- **行内代码**、` fenced 代码块 `（带语法高亮）
- 表格、引用块、任务列表
- 图片（可外链任意图床）

代码高亮示例：

```javascript
// 文章里可以随意贴代码
function greet(name) {
  console.log(`Hello, ${name}!`);
}
greet("观澜阁");
```

## 小建议

1. **文件名即网址**：用 `my-post.md` 而不是 `我的文章.md`
2. **一篇一个主题**：短而聚焦胜过长而涣散
3. **写完摘要再发布**：excerpt 决定读者是否点进来

> 现在，去写你的第一篇文章吧。
