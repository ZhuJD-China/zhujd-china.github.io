## 1. 前传：比特币脚本的天花板（2010-2013）

比特币的脚本系统（Script）是有意设计得不图灵完备的。它是一组有限的、不可循环的指令，能做的事大致是：验签、哈希锁定、时间锁定、多重签名。中本聪这样设计的原因很直接：给脚本图灵完备性，等于给全网每个节点一个可以无限循环的炸弹，任何攻击者都能让矿工空转到死。

这个取舍在 2009 年完全合理。但到 2010 年代初，一批人开始在比特币上"叠层"，试图在不改主协议的前提下塞进更多功能：

- **Namecoin（2010）**：去中心化域名注册，用"先到先得"的共识登记 .bit 域名；
- **染色币（Colored Coins，2012-2013）**：给特定的比特币 UTXO 涂上"颜色"，让它代表股票、黄金或另一种货币——本质是把比特币当资产登记处用；
- **万事达币（Mastercoin，2012-2013）**：在比特币交易的 op_return 里塞自定义协议数据，支持对冲、期权、去中心化交易所等金融合约。

这些项目被称为"加密货币 2.0"（Cryptocurrency 2.0）。它们的共同问题是：所有聪明的想法都必须挤进一个为转账设计的脚本空间里，每加一个功能就要全体讨论一次协议升级，而且互相不兼容——染色币的代币不能和万事达币的合约直接交互，因为它们各自解释同一段比特币数据的方式不同。

2013 年的 Vitalik Buterin 19 岁，为 Bitcoin Magazine 跑遍这些项目。他参与了染色币、智能财产、去中心化交易所等多个方案的设计，越做越确信"在别人的协议上打补丁"这条路走不通。缺的不是想法，是一个通用的底层：一个能写任意状态转换函数的区块链。

## 2. 2013：一份被拒绝的提案

以太坊的起点不是白皮书，是一份没被采纳的提案。

2013 年 10 月，Vitalik 访问以色列，与万事达币团队泡了很久，甚至建议他们加几个功能。越想越觉得该团队的架构太特化，他写了一份提案，提议把万事达币协议改得更通用，支持更多种类的合约，而不必为每个新功能堆一套复杂指令。万事达币团队表示印象很深，但没有兴趣放弃已有的一切去转向这个方向。

Vitalik 越来越确信这个方向是对的。2013 年 11 月，他在旧金山一次长距离散步中想通了关键一步：智能合约应该是完全通用的——合约本身就是完整的账户，能持有、发送、接收资产，甚至维持永久存储，而不是只用一段脚本描述双方关系。这份想法成了白皮书第一版的底稿。

按 Vitalik 2017 年那篇《以太坊协议的史前史》（A Prehistory of the Ethereum Protocol）的回忆，时间线是：

| 时间 | 事件 |
| --- | --- |
| 2013-10 | 访问以色列，向万事达币提交通用化提案，被婉拒 |
| 2013-11 | 旧金山散步后完成白皮书初稿（此时还没有"以太坊"这个名字） |
| 2013-12 | 第二版重写：合约成为账户，虚拟机从栈式改为寄存器式；Gavin Wood 通过 about.me 私信联系上 Vitalik |
| 2013-12 | Gavin Wood 与 Jeffrey Wilcke 前后脚开始写 C++ 与 Go 两个客户端 |
| 2014-01 | 迈阿密北美比特币会议正式宣布以太坊，八位联合创始人聚齐 |
| 2014-04 | Gavin Wood 发布黄皮书（Ethereum Yellow Paper）初版 |
| 2014-06/07 | 以太坊瑞士公司与以太坊基金会（Stiftung Ethereum）在瑞士楚格成立 |
| 2014-07-22 至 09-02 | 42 天以太币众筹 |
| 2014-11-24 | DEVCON-0 在柏林举办，Solidity 首批合约上测试网 |
| 2015-03 | PoC9 与 Olympic 测试网 |
| 2015-07-30 | Frontier 主网启动 |

名字的来历也值得记一笔：Vitalik 翻维基百科的科幻列表选中了 "Ethereum"——"以太"，那个曾被物理学抛弃的、被认为充满宇宙并承载光传播的不可见介质。他想要的正是这个隐喻：一层看不见的底层，应用跑在上面而不必知道它在哪。

## 3. 白皮书的四个版本

《以太坊白皮书》不是一次写成的，它至少有四个可考的形态。

**第一版（2013-11）**：还寄生在万事达币的语境里，标题接近"通用化万事达币"，功能局限于双方合约，脚本非图灵完备。

**第二版（2013-12，存档于 web.archive.org 的 vitalik.ca/ethereum.html）**：标题变成 "Ethereum: The Ultimate Smart Contract and Autonomous Corporation Platform on the Blockchain"。这一版完成了架构跃迁——合约是账户、有永久存储、虚拟机改为寄存器式；货币一节首次出现 ether，写明"理论上限 2^128 单位"，并给出了"0.25X 给创始人、0.25X 给组织储备、0.5X 永久线性增发"的原始分配方案。此时方案还有两个后来被推翻的设计：永久线性通胀、按笔收取 PoW 式的费用。

**第三版（2014 年初）**：在 Andrew Miller 等人建议下，虚拟机改回栈式（更简单、更适合形式化验证）；费用模型重构为 gas——发起交易的人预付一笔 ether，换回一个"计算步数计数器"，而不是每个指令执行后当场扣币。这一改动解决了两个问题：防止无限循环合约耗尽全网资源，以及让交易费用与计算量精确挂钩。gas 的设计沿用至今。

**定稿（2014 年，上线前）**：标题改为今天的《Ethereum: A Next-Generation Smart Contract and Decentralized Application Platform》。核心主张一句话：与其在比特币上继续打补丁，不如造一个内置图灵完备语言的区块链，让任何人都能用几行代码定义自己的所有权规则、交易格式和状态转换函数。文中的名句是："一个精简版 Namecoin 可以用两行代码写出来，货币和声誉系统之类的协议可以在二十行以内构建。"

白皮书里与比特币正面分歧的技术选择：

| 问题 | 比特币 | 以太坊白皮书 |
| --- | --- | --- |
| 账本模型 | UTXO（未花费输出） | 账户模型（address + balance + nonce + code + storage） |
| 脚本能力 | 非图灵完备，防循环炸弹 | 图灵完备，用 gas 计量兜底 |
| 状态 | 隐含在 UTXO 集合中 | 显式的状态树，每块更新 |
| 出块间隔 | 10 分钟 | 约 12 秒（引入 GHOST 协议弥补废块率） |
| 费用 | 按字节的市场竞价 | gas × gas price，计算量定价 |

GHOST（Greedy Heaviest Observed Subtree）来自 Sompolinsky 与 Zohar 2013 年 12 月的论文：把废块（叔块）计入共识与奖励，缓解短出块间隔带来的安全损失与矿池中心化。这是以太坊从第一天起就与比特币分道的技术路线：比特币用长出块换安全，以太坊用 GHOST 换速度。

## 4. 黄皮书：把散文变成数学

白皮书是愿景文档，黄皮书是工程图纸。后者由 Gavin Wood 执笔，初版 2014 年 4 月发布，标题是《Ethereum: A Secure Decentralised Generalised Transaction Ledger》。它做了一件此前区块链项目几乎没人做过的事：用形式化数学语言把整条协议写到可以被多个独立实现精确复现的程度——状态转换函数、交易执行的每一步、gas 的扣减公式、默克尔帕特里夏树的定义，全部是带编号的定义、公理和等式。

黄皮书的存在直接决定了以太坊早期的开发形态：C++（Gavin）、Go（Jeffrey Wilcke）、Python（Vitalik 本人的 pyethereum）、Java、JavaScript、Haskell、Rust 七个客户端团队拿着同一份规范各自实现，再用同一批测试向量对齐共识。一个 2014 年的项目敢这么做，前提是规范足够严格。

黄皮书还固化了几个白皮书没有定死的细节：EVM 的栈深限制、字长（256 位）与操作码语义；叔块（ommer）的奖励规则——叔块矿工仍能获得大部分区块奖励，收录叔块的矿工获得小额额外奖励；交易收据（receipt）与日志（logs）的结构，这一设计后来成了事件查询与轻客户端的基础。

## 5. 源码考古：创世区块与 go-ethereum

以太坊没有"一个人写一万行 C++"式的起点，它从第一天就是多实现并行。但所有实现共享同一个创世区块。今天在 go-ethereum 的 `core/genesis.go` 里，`DefaultGenesisBlock()` 长这样：

```go
func DefaultGenesisBlock() *Genesis {
	return &Genesis{
		Config:     params.MainnetChainConfig,
		Nonce:      66,
		ExtraData:  hexutil.MustDecode("0x11bbe8db4e347b4e8c937c1c8370e4b5ed33adb3db69cbdb7a38e1e50b1b82fa"),
		GasLimit:   5000,
		Difficulty: big.NewInt(17179869184),
		Alloc:      decodePrealloc(mainnetAllocData),
	}
}
```

创世哈希的常量在 `params/config.go` 里：

```go
MainnetGenesisHash = common.HexToHash("0xd4e56740f876aef8c010b86a40d5f56745a118d0906a34e69aec8c0db1cb8fa3")
```

逐项拆开：

- `Nonce: 66`（即 0x42）——《银河系漫游指南》里"生命、宇宙及一切的终极答案"。比特币的创世 nonce 是硬编码的挖矿结果，以太坊的创世 nonce 是一个玩笑，因为这条链的创世块不需要任何人去挖；
- `Difficulty: 17179869184`（即 0x400000000）——一个整齐的整数，象征性的起始难度；
- `GasLimit: 5000`——创世块的 gas 上限只有 5000，低到几乎什么都做不了。这是刻意的：启动时只允许最基础的操作，网络上线后由矿工逐块投票抬高上限（早期规则允许每个区块的 gas limit 相对上一区块浮动约 1/1024），把"扩容"变成了链上治理的第一个练习；
- `ExtraData`——一段 32 字节的哈希填充，不含可读信息；
- `Alloc`——创世预分配表，约 7200 万枚 ETH 中的绝大部分在创世块里直接写好余额：约 6010 万枚对应众筹参与者，约 1190 万枚留给早期贡献者与基金会。这是与比特币最刺眼的对比：比特币的币从 coinbase 里一块一块挖出来，以太坊的币在区块高度 0 就已经分完了大半。

创世块哈希 `0xd4e56740…8c0db1cb8fa3` 至今是所有以太坊客户端校验自己是否连对网络的第一道闸——如果创世哈希不一致，你的"以太坊"就是另一条链。

另一处源码层面的分野是记账模型。比特币的 `ConnectInputs` 用 `vSpent` 数组检查双花（见上一篇第 5 节），以太坊则完全抛弃了 UTXO，改用账户余额加 nonce：

```go
// 账户模型的直觉版本（伪代码，对应黄皮书的形式化定义）
type Account struct {
	Nonce    uint64      // 交易计数器，防重放
	Balance  *big.Int    // 余额（wei）
	Root     common.Hash // 状态树根（合约存储）
	CodeHash []byte      // 合约代码哈希（外部账户为空）
}
```

每个区块维护一棵全局状态树（Merkle Patricia Trie），交易执行就是一次状态转换：σ' = A(σ, T)——给定当前状态 σ 和交易 T，确定性地算出新状态 σ'。合约代码存在账户里，调用合约就是让 EVM 执行这段字节码，gas 用尽则回滚。"区块链即世界计算机"在数据结构层面的含义是：一台全网共识维护的、状态不可篡改的确定性状态机。这是比特币账本模型上从未有过的抽象层级。

## 6. 众筹：31,591 枚比特币买来的一条链

软件可以开源写，法律实体、工资和服务器账单没法开源解决。2014 年 1 月的迈阿密会议上，团队就定下了 Mastercoin 式的众筹路线：用比特币换未来的 ether。中途方案多次修改，最终条款是 42 天（2014-07-22 至 09-02），价格从 2000 ETH/BTC 逐档递减至约 1337 ETH/BTC。

| 项目 | 数字 |
| --- | --- |
| 筹得比特币 | 31,591 BTC |
| 当时美元价值 | 约 1840 万美元 |
| 售出 ether | 约 60,102,216 枚 |
| 法律实体 | Ethereum Suisse GmbH（苏黎世）+ Stiftung Ethereum（楚格，2014 年年中成立） |
| 开发管理 | 非营利组织 ETH DEV，三位主管：Vitalik Buterin、Gavin Wood、Jeffrey Wilcke |

这笔众筹后来被反复当作"ICO 模式"的原型来研究，但有两点常被忽略。第一，众筹发生在软件存在之前，买家拿到的是一份条款声明和一串未来记账的承诺——这在 2014 年需要相当的信任，也正因如此，团队才要先成立瑞士法律实体再开卖。第二，以太坊的众筹没有预留"团队份额按年解锁"这种后来流行的机制，分配是一次性的，这为 2016 年 DAO 事件之后的治理冲突埋下了伏笔（那是另一篇的事）。

## 7. 七种语言、九个 PoC 与四个月测试网

2014-2015 年的开发节奏可以概括为：概念验证（Proof of Concept）系列从 PoC1 推到 PoC9，每个版本对应一次协议修订。同期发生的事：

- **多客户端并行**：C++（Gavin Wood 主导）、Go（Jeffrey Wilcke）、Python（pyethereum）、Java、JavaScript、Haskell、Rust 相继开工。Go 客户端后来更名为 go-ethereum（geth），C++ 客户端叫 cpp-ethereum（aleth）——前者活到了今天，后者在 2016 年后逐渐退役；
- **Solidity 诞生**：最初的语言是 Vitalik 写的类 Python 的 Serpent 和 LLL，2014 年 Gavin Wood 与 Christian Reitwißner 设计了合约导向、静态类型、语法接近 JavaScript 的 Solidity。2014 年 11 月的 DEVCON-0 上，首批 Solidity 合约已在测试网运行——这次会议是项目第一次把散布柏林、阿姆斯特丹、旧金山的开发者聚到同一间屋子里，Gavin Wood 开场白是："进步导致了权力的集中，因此我们的使命是去中心化。"
- **挖矿算法的反复**：从 Dagger、自适应 PoW、随机电路一路改到 Ethash（Dagger-Hashimoto），目标是抗 ASIC 且对轻客户端友好——与比特币最终被 ASIC 统治的路径形成对照；
- **安全审计**：2014 年底到 2015 年上半年，Least Authority（Andrew Miller 等）与 Ittay Eyal（自私挖矿论文作者）分别对合约层、gas 经济学、帕特里夏树和共识层做了两轮审计，直接导致了几处协议修订，包括总难度计算排除叔块、树键使用哈希等；
- **Olympic 测试网**：PoC9 之后运行了约四个月的公开测试网，前两个月各实现频繁出现 bug 和共识失败，6 月前后网络明显稳定，7 月冻结代码。团队还悬赏挑战者——谁能打破测试网记录就能拿奖金，这是主网上线前的压力测试。

这套流程在今天的区块链行业是常识，在 2014 年近乎奢侈：先形式化规范，再多实现，再第三方审计，再长期测试网，最后才碰主网。以太坊早期的工程声誉，基本是在这二十个月里攒下的。

## 8. Frontier：2015 年 7 月 30 日

Vinay Gupta 那篇《以太坊的发布过程》把主网切成四阶段：Frontier（边境）、Homestead（家园）、Metropolis（大都会）、Serenity（宁静）。2015 年 7 月 30 日启动的是 Frontier——名字说明了定位：开发者版本，功能残缺（最初几天只能挖矿，交易和合约功能随后开放），gas 限制严苛，钱包粗糙。

但它是第一条真正跑起来的"通用世界计算机"。上线后的几个事实：

- 创世块之后，网络以约 12-15 秒的间隔出块，区块奖励 5 ETH；
- 2015 年 9 月 8 日（区块 200,000），"冰河世纪"（Ice Age）难度炸弹启动——出块难度开始指数上涨，迫使社区在转向 PoS 前讨论难度表的调整。这个机制此后被推迟过无数次，成了以太坊治理史的常驻角色；
- 2016 年 3 月 14 日（区块 1,150,000），Homestead 激活，标志网络"准备好了"；
- 之后的故事所有人都知道了：The DAO、分叉成 ETC 与 ETH、ICO 浪潮、DeFi、NFT、2022 年合并（The Merge）转 PoS。

Frontier 启动那天，没有交易所上线、没有机构持仓、没有 NFT。以太坊的"生态"要再等两年才爆发，而它爆发的形态（ERC-20 众筹、DAO、DeFi）没有一个出现在 2013 年的白皮书里——白皮书给的是原语，生态长出来的是谁都没料到的东西。这一点倒是和比特币一脉相承：创造者定义协议的边界，不定义边界的用途。

## 9. 为什么是它接过了第二棒

第一，它补的是真实缺口。比特币证明了去中心化账本可行，也暴露了它的边界：脚本不图灵完备，每加一个应用都要全体升级协议。以太坊的回应不是"更好的货币"，是"通用的状态机"——把区块链从产品变成平台。这是计算机史上反复出现的跃迁：从专用机到通用机，从指令集到操作系统。

第二，工程路径罕见地正统。先形式化规范（黄皮书），再多实现对齐（七种语言），再第三方审计，再四个月测试网，最后小步启动（Frontier）。这条路径后来被无数公链模仿，完整走完的不多。

第三，时机与资本结构。2014 年的众筹筹到的 1840 万美元在当时是天文数字，足够养一支全职团队跑完二十个月——比特币靠中本聪一个人业余写完 v0.1，以太坊靠基金会雇佣几十名全职开发者。两种模式都成功过，但"通用平台"的复杂度决定了后者才可行。

## 10. 尾声

从 2013 年那份被万事达币拒绝的提案，到 2015 年 7 月 30 日的创世块，以太坊用了二十个月。这个速度在传统软件史里也算快，而在需要同时发明语言（Solidity）、虚拟机（EVM）、共识规则和治理模式的领域，它几乎是一次异常值。代价同样清楚：预分配的合法性争议、DAO 分叉的治理创伤、PoW 转 PoS 的十年长跑，全部写在起源的基因里。
