## 1. 问题：链上为什么需要一美元

2011 年到 2013 年，比特币交易所的报价方式从"多少美元一个比特币"逐渐过渡到"多少比特币一个美元"。这句话的倒装里藏着一个问题：当计价单位本身每天波动 5% 到 10% 时，交易所很难用它清算、商家很难用它标价、做空的人很难保证金。市场缺的不是新的投资品，是一个能在链上直接转账的美元记账单位。

它必须同时满足三个条件：价格稳定、可以自由转移、转移发生在区块链上（即不依赖银行营业时间，也不依赖每笔电汇）。2014 年前后出现了一批早期尝试：BitUSD、NuBits 走的是加密资产超额抵押加价格预言机的路子，锚定效果依赖市场套利；另一条更朴素的路是法币抵押型——公司在银行里存 1 美元，在链上发行 1 个代币，承诺凭币可兑。今天占据 60% 份额的 USDT 走的是后一条路，它的身世并不"原生"，而是从比特币的一个扩展协议里长出来的。

## 2. 身世：从万事达币里长出来的 Realcoin

2012 年，J. R. Willett 发布白皮书，提出在比特币区块链之上再建一种货币的可能。这个想法的实现叫万事达币（Mastercoin），后来改名 Omni，其基金会叫 Omni Foundation。上一篇提到过它：Vitalik 2013 年那仛建立以太坊的直接诱因，就是被万事达币团队拒绝的"通用化"提案。万事达币自己没有通用化，但把一个具体功能做透了——在比特币的 OP_RETURN 里塞自定义协议数据，管理自定义资产。

Tether 的三位联合创始人都来自这个圈子：Brock Pierce 是万事达币基金会原始成员，Craig Sellars 是基金会 CTO，Reeve Collins 负责商业。2014 年 7 月，三人在加州圣塔莫尼卡宣布 Realcoin 项目；9 月在英属维尔京群岛注册公司；10 月 6 日，第一批代币在比特币区块链上发行，用的正是 Omni Layer 协议。11 月 20 日，项目改名 Tether，进入私测，支持三种币：对应美元的 US+、对应欧元的 EU+、对应日元的 JP+。宣传语是"每个 Tether+ 代币都以其原始货币 100% 价值作为支持，可以随时无风险地兑换"。

从时间线能看出产品与公关的分工：先发币（10 月 6 日），再改名（11 月 20 日）。Tether 与当时最大比特币交易所之一 Bitfinex 的关系在早期刻意保持模糊，新闻稿把 Bitfinex 列为"伙伴"；后来两家被发现共用 CEO、CFO 和董事长，同属 iFinex 旗下。这条关系线会贯穿本文余下的所有争议。

## 3. Omni 层上的美元：在比特币交易里记账

Omni 层的发币思路继承自万事达币：不改比特币主协议，把资产的发行与转移写成"消息"，挂在比特币交易的 OP_RETURN 输出里，由运行 Omni 客户端的节点解释执行。USDT 的链上账本因此分两层：比特币负责排序和防篡改，Omni 负责解释"这笔转账其实是 property 31 的转账"。

一笔 Omni simple send 的载荷字段结构如下（实际以十六进制写入 OP_RETURN，单位均为 4 字节，property id 与 amount 各占 8 字节）：

```text
0000              message type = 0（simple send）
0000              version = 0
00000000 0000001F property id = 31（USD₮）
00000000 XXXXXXXX amount（最小单位）
```

这种设计的直接后果是：USDT 的发行记录完全公开，Omni 浏览器上每一笔增发、销毁、转账都可查。链上透明解决的是"有没有发"的问题，解决不了"银行里有没有钱"的问题——后者只能靠发行方自己披露。这一点构成了稳定币此后十年全部争议的分界线：链下储备是私有信息，链上数量是公开信息，两者的对账没有技术方案，只有会计方案。

早期的量很小：2015 年 5 月总供应量才 45 万枚，2016 年全年增发约 600 万枚。真正的放量发生在 2017 年牛市，当年增发约 14 亿枚。2017 年 11 月 19 日，约 3100 万美元的 USDT 从 Tether 储备钱包被转到未经授权的比特币地址，Tether 随后通过 Omni 层的一次硬分叉把被盗地址冻结。这件事在当时就被质疑"监守自盗"，至今没有定论。

## 4. 源码考古：以太坊上的 USDT（2017）

2017 年 10 月，USDT 登陆以太坊；同月上链的代码在 11 月 28 日提交到 Etherscan 验证。与今天的以太坊代码相比，这份合约粗糙得像个 2017 年该有的样子：Solidity 0.4.x 时代，没有 SafeMath（部分函数手工做溢出检查），升级机制靠一个 `deprecated` 布尔开关转发调用。但它有两个发币合约的"现场"，值得逐行看。

```solidity
function issue(uint amount) public onlyOwner {
    require(_totalSupply + amount > _totalSupply);
    require(balances[owner] + amount > balances[owner]);
    balances[owner] += amount;
    _totalSupply += amount;
    Issue(amount);
}

function redeem(uint amount) public onlyOwner {
    require(_totalSupply >= amount);
    require(balances[owner] >= amount);
    _totalSupply -= amount;
    balances[owner] -= amount;
    Redeem(amount);
}
```

`issue` 与 `redeem` 是整个 USDT 的信任核心：增发与销毁都只听 owner 一个人的，链上没有任何第三方能验证 `require` 之外的东西。两个手工溢出检查就是这份合约的全部"审计"。2018 年 1 月 3 日 OpenZeppelin 发布的审计报告列出的问题包括：`issue` 里没有按 ERC-20 规范发出 `Transfer(0x0, ...)` 事件（新增代币在区块浏览器上因此一度不可见，后已修复）、`issue`/`redeem` 里未检查的算术运算、以及黑名单的检查没有放在黑名单合约里而是手工塞进 `transfer` 的函数体。

黑名单长这样：

```solidity
function destroyBlackFunds(address _blackListedUser) public onlyOwner {
    require(isBlackListed[_blackListedUser]);
    uint dirtyFunds = balanceOf(_blackListedUser);
    balances[_blackListedUser] = 0;
    _totalSupply -= dirtyFunds;
    DestroyedBlackFunds(_blackListedUser, dirtyFunds);
}
```

`addBlackList` 把地址标脏，`destroyBlackFunds` 直接把它的余额清零并销毁总量。也就是说，早在 2017 年，USDT 就具备了"冻结任意地址的余额"的能力，而且销毁的钱不返还给持有人，直接从总供应量里抹掉。审计报告把它列为 owner 权限风险之一。今天在 Etherscan 上查询黑名单地址，读的就是 `isBlackListed` 这张映射表。

还有一处容易被忽略的设计：`deprecate(address _upgradedAddress)` 允许 owner 把整个合约标记为弃用，之后所有 `transfer`、`balanceOf` 都转发到新地址。这不是后来流行的代理模式，而是一种粗暴的"人工分叉"，旧合约的每个函数体里都写着一段转发逻辑。同一时期的代码里还有为防短地址攻击而写的 `onlyPayloadSize` 修饰器，后来被证明会误伤多签钱包的调用。

## 5. 源码考古：USDC 与 FiatToken 的四顶帽子

USDT 的代码是先上线再补规范，USDC 反过来。Circle 与 Coinbase 2018 年 9 月 26 日推出 USDC，通过合资公司 CENTRE 运作，代码从第一天就按可审计的标准写，仓库现称 `circlefin/stablecoin-evm`（早期为 `centrehq/centre-tokens`）。核心合约 FiatToken 把权限拆成四个角色，README 里列得很清楚：

| 角色 | 职责 |
| --- | --- |
| `owner` | 合约所有者，可更换其他三个角色 |
| `masterMinter` | 增删 minter，分配每个 minter 的铸造额度 |
| `minters` | 实际铸造与销毁代币 |
| `pauser` | 暂停全部转账、铸造、销毁 |
| `blacklister` | 冻结指定地址的转账、收币、铸造、销毁 |

权限检查的实现非常直白：

```solidity
modifier onlyBlacklister() {
    require(
        msg.sender == blacklister,
        "Blacklistable: caller is not the blacklister"
    );
    _;
}

modifier notBlacklisted(address _account) {
    require(
        !_isBlacklisted(_account),
        "Blacklistable: account is blacklisted"
    );
    _;
}

function blacklist(address _account) external onlyBlacklister {
    _blacklist(_account);
    emit Blacklisted(_account);
}
```

和 USDT 的对比有三层。第一，铸造权限从"一个 owner"细化为额度制的多 minter，每个 minter 有 `minterAllowed` 上限，这是把公司内部的发行流程直接编码进合约。第二，升级走标准的代理模式（`FiatTokenProxy` 指向实现合约），而不是 USDT 那种逐函数转发的人工分叉；换实现版本时旧地址上的余额、黑名单原样保留。第三，黑名单检查被提到 `notBlacklisted` 修饰器这一层，`transfer`、`transferFrom`、`mint`、`burn` 全部统一挂上，不再依赖每个函数手写一行 `require`。

即便如此，FiatToken 里仍有一个值得称道的细节——为了省钱，v2.2 版本把黑名单状态从单独的映射挪进了余额的最高位：

```solidity
/// @dev A mapping that stores the balance and blacklist states for a given address.
/// The first bit defines whether the address is blacklisted (1 if blacklisted, 0 if not).
/// The last 255 bits define the balance for the address.
mapping(address => uint256) internal balanceAndBlacklistStates;
```

PR #357 的说明算过一笔账：2022 年 6 月一个月里，这项改动能为 USDC 用户省下约 70 万美元 gas。一个发行 700 亿美元的代币，仍然在为一次存储读取的 2100 gas 认真优化，这是合规项目和野路子项目的共同语言。

代码之外，USDC 与 USDT 的另一个本质差别在发行链的选择：USDT 先在比特币 Omni 层，2017 年上以太坊，2019 年起在波场（TRC-20）放量，今天波场一条链承载约 924 亿美元，超过以太坊的 729 亿美元，原因是波场转账费低、交易所充值到账快，成了亚洲场外交易与交易所间划转的主力通道。USDC 则始终以以太坊为主（约 453 亿美元），外加 Solana、Base、Hyperliquid 等偏机构与 DeFi 的链。两个代币的链分布，就是两类用户画像的链上指纹。

## 6. 信任的编年史：从审计报告到 1850 万美元和解

储备披露这条线上，USDT 的每一步都是被追问出来的：

| 时间 | 事件 |
| --- | --- |
| 2017-09-28 | Friedman LLP 出具报告，称银行账户 4.43 亿美元与流通的约 4.42 亿 USDT 相当；不披露开户行名称 |
| 2018-06 | 律所 Freeh Sporkin & Sullivan（FSS）出具说明文件，称存有 25.5 亿美元；仍无银行名称，且并非审计 |
| 2018-11-01 | Tether 宣布与巴哈马 Deltec 银行合作，附一封存款证明信，落款是无姓名的波浪签名 |
| 2019-02-25 | 起诉前夕，官网条款从"每 1 枚 USDT 始终由储备中的 1 美元 1:1 支持"改为"100% 由 Tether 储备支持"，储备定义扩至现金等价物、贷款应收款等 |
| 2019-04-25 | 纽约总检察长（NYAG）起诉 iFinex，指控 Bitfinex 有约 8.5 亿美元资金困于支付服务商 Crypto Capital，Tether 动用储备填补 |
| 2019-04-30 | Tether 总法律顾问在宣誓书中承认，按狭义现金口径只有 74% 的 USDT 有美元支持 |
| 2021-02-23 | 双方以 1850 万美元和解，Tether 同意按季披露储备分类，不承认不当行为 |
| 2021-10-15 | 美国 CFTC 罚款 4160 万美元，认定 2016-2018 年间只有 27.6% 的日子足额持有美元储备 |
| 2021-05 后 | 储备报告披露现金仅占 2.9%，商业票据占 49.6%；此后逐步清仓，2022 年底商业票据归零，换成短期美债 |
| 2026-08-13 | KPMG 对 2025 年财报出具无保留意见，为首次完整审计，年末储备超出负债 68.14 亿美元 |

2019 年宣誓书里的 74% 是整条时间线的分水岭。在此之前，"1:1 美元"是营销话术；在此之后，各方都把措辞收缩为"100% 由储备支持"——这两个短语的差别，就是现金与"现金、商业票据、应收款、贷款"的差别。NYAG 的和解声明里说得直白：声称 USDT 任何时候都完全由美元支持是谎言。而支持者会指出另一面：这十年里 USDT 没有出现过一次无法兑付的挤兑，2026 年首次完整审计给出的 68 亿美元缓冲也远超历史水平。争论的实质从来不是"够不够"，而是"按谁的口径算、谁来数"。

USDC 这边的披露节奏一直更紧：月度四大会计师事务所鉴证、每周持仓披露，储备放在贝莱德管理的政府货币市场基金（Circle Reserve Fund）加少数几家大行的现金里。这种安排的脆弱点在 2023 年 3 月暴露了一次，见下一节。

## 7. 两次脱锚：SVB 的三天与算法稳定币的对照

2023 年 3 月 10 日，硅谷银行（SVB）被接管，Circle 随即披露 30 亿美元级别的 USDC 储备（33 亿美元口径见于多方报道）存放在该行。USDC 迅速跌到 0.87 美元附近，脱锚持续到 3 月 12 日美国政府宣布保护全部存款、Circle 承诺通过新银行通道结算赎回之后，价格才逐步回到 1 美元。三天时间里，链上出现了大量 `USDC → USDT` 的避险换仓，事后看它成了"两家发行方、同一套银行体系"这个集中度风险的现场演示。

另一次脱锚属于不同物种。2022 年 5 月，算法稳定币 UST 崩盘，靠的是套利者对 1 美元承诺的博弈，没有真实储备，几天内从 1 美元跌到 0.10 美元以下，连带 400 亿美元级别的 Luna 生态蒸发。这次崩塌把市场教育成了两派：一派从此只认法币抵押型，另一派由此对所有稳定币都打问号。

对 USDT 的质疑集中在另一条线上。2018 年 Griffin 与 Shamsky 的论文认为 Tether 增发与比特币价格存在关联、疑似操纵，Bitfinex 反驳其数据选取有偏；后续多项研究未能复现操纵结论，2022 年的一项研究发现价格反应主要出现在 Whale Alert 公开披露增发消息之后，更像市场对新闻的正常反应。这组文献至今没有定论，可以确定的只有两条事实：USDT 的增发是 owner 一行 `issue` 调用就能完成的，而储备披露直到 2021 年才被监管强制成形。

## 8. 2026 年的牌桌

截至 2026 年 10 月上旬，链上统计的美元稳定币总供应约 3110 亿到 3130 亿美元，其中：

| 代币 | 发行方 | 流通量 | 份额 | 主要链 |
| --- | --- | --- | --- | --- |
| USDT | Tether International（萨尔瓦多注册主体） | 约 1832 亿美元 | 58.8% | 波场 924 亿、以太坊 729 亿 |
| USDC | Circle | 约 731 亿美元 | 23.5% | 以太坊 453 亿、Hyperliquid、Solana、Base |
| USDS / USDe / DAI 等 | Sky、Ethena、Maker 等 | 合计约 160 亿美元 | 约 5% | 分散 |

两家合计占 83%。储备口径也已趋同但仍有差别：USDT 以美国国债与逆回购为主（2026 年一季度 BDO 鉴证报告口径约 1410 亿美元美债敞口），另持有约 200 亿美元实物黄金、约 70 亿美元比特币及担保贷款，季度由 BDO 鉴证；2026 年二季度总资产 1877.5 亿美元对负债 1836.4 亿美元，缓冲 41.1 亿美元，比一季度的 82.3 亿美元缩水过半（官方解释是黄金与比特币的季度波动）。USDC 则是现金加短久期国债加逆回购，部分放在政府货基里，月度鉴证。差别在于：GENIUS 法案认可的储备清单里没有黄金和比特币，这一条会在 2027 年变成实质性的分水岭。

一个容易被数字掩盖的事实：两个代币的持有人绝大多数不直接找发行方赎回，而是找交易所或做市商换美元。也就是说，1 美元的价格锚主要由二级市场的套利者维持，发行方的储备只是这套机制的最终靠山。审计改变的是靠山的可信度，不改变套利的机制。

## 9. 监管落地：MiCA 与 GENIUS 法案

欧洲的 MiCA 先行：2024 年 7 月 1 日起，稳定币（asset-referenced token 与 e-money token）进入发牌时代，Circle 拿到电子货币代币发行资质，Tether 不在 ESMA 名单内，随后于 2024 年 11 月停止支持欧元币 EURT。

美国的答案是 2025 年 7 月 18 日签署的 GENIUS 法案：支付型稳定币须 1:1 持有合格储备（美元与活期存款、剩余期限 93 天以内的国债、以国债为抵押的回购、政府货基）、按月公开披露并经独立会计师鉴证、向联邦或合格州监管机构注册、遵守反洗钱义务、不得向持有人支付利息。生效日取"立法后 18 个月"与"最终规则落地后 120 天"之较早者，目前锚定 2027 年 1 月 18 日；2028 年 7 月 18 日起，美国的交易所与钱包只能向用户分发持牌发行方的稳定币。

Tether 的应对是两步：宣布 USDT 继续作为离岸产品运营、向合规靠拢，同时于 2026 年 1 月推出由 Anchorage Digital Bank 发行、专为 GENIUS 框架设计的 USAT。禁息条款同样值得留意——它把稳定币和代币化货基、收益型代币划清了界线，也意味着"用 USDT 吃利息"这条灰色产品线在美国法律下被关上了门。

## 10. 稳定币成了国债买家

把前九节的线索收拢，会得到一个 2014 年的创业者没料到的结局：这个起初为交易所清算发明的小工具，成了美国短期国债的边际买家。

数字在放大。美国财政部借款咨询委员会（TBAC）估算，截至 2024 年底主要发行方持有的短期国债已超 1200 亿美元，其中 Tether 直接持有约 945 亿、Circle 的货基持有约 533 亿（自报口径，未经独立验证），并推算若市场继续扩张，2028 年这一需求可能增至约 1 万亿美元。BIS 的研究（Working Paper 1270）则在更细的尺度上量出了传导：约 35 亿美元的稳定币资金流入，能在 10 天内把 3 个月期国债收益率压低约 4 个基点。美联储工作人员的长期预测区间是到本世纪末稳定币规模 1 万亿到 3 万亿美元——而全市场 3 个月以内的国债权威总量也不到 7 万亿美元。

GENIUS 法案把这条通道写进了法条：合格储备限定在 93 天以内的短债与回购，等于给"发行稳定币"和"买美国短债"焊死了连线。批评者因此说稳定币正在变成影子银行并给美元计价资产制造新的杠杆依赖；支持者则认为这不过是把离岸美元融资的一部分搬到了链上，且按月披露比银行体系更透明。这场辩论没有终局，但结构已经很清楚：稳定币的储备政策从此既是风险管理问题，也是利率问题。

## 11. 尾声与预告

回到开头的问题：一个"永远等于一美元"的代币，凭什么等于一美元。三篇文章写到这里，答案已经分层：链上部分靠的是发行方的一个函数（`issue`/`blacklist`）和区块链的公开账本；链下部分靠的是银行账户、会计鉴证与监管强制；市场价格靠的是做市商的套利。三层各自都出过事，三层也各自都在 2026 年比 2014 年结实。

对普通用户而言，实践层面的结论只有三条：看发行方而不只看代币符号，看储备构成而不只看"100%"这个词，看自己拿的是代币还是对发行方的债权——这两样东西在 2028 年美国的分发规则生效后，会进一步分化成两类资产。

下一篇回到结构：UTXO 与账户模型的对照、一笔交易的十六进制解剖、以及"余额"这个词在比特币和以太坊账本里根本不是同一种东西。

> 文中市值、份额与储备数据来自 DeFiLlama、发行方公告、BDO/KPMG 鉴证摘要与第三方研究，统计口径与时间点不同会有出入；Tether 与 Bitfinex 的关联基于双方共用高管等公开信息，和解中两家不承认不当行为；对 USDT 操纵比特币价格的指控至今是学术争议，本文仅陈述各方立场。
