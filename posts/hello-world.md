# 你好，世界

这是 **观澜阁** 的第一篇文章。

每一个博客的第一篇文章，都绕不开这句经典的 "Hello, World"。它是一种仪式 —— 从这一刻起，我开始在这里记录技术、思考与生活。

## 为什么是"观澜阁"

> 观水有术，必观其澜。—— 《孟子·尽心上》

技术的浪潮奔涌向前，与其随波逐流，不如**静观其澜**：

- 观，是输入 —— 阅读源码、论文与他人的经验
- 澜，是思考 —— 在纷繁现象中抓住本质
- 行，是输出 —— 把理解沉淀为文字与代码

## 这个博客如何运作

本站基于 **GitHub Pages** 纯静态搭建，没有后端、没有数据库：

1. 所有文章都是 `posts/` 目录下的 Markdown 文件
2. 博客引擎通过 GitHub API 自动发现文章
3. 写完 `.md` 文件推送，网站即刻更新

简单、纯粹、专注内容本身。

## 接下来

作为一名数据科学与人工智能学者，这里会陆续记录：

- **研究笔记** —— 机器学习、深度学习与统计建模的探索
- **技术实践** —— 数据、代码与工程上踩过的坑
- **思考随笔** —— 智能时代的观察，以及代码之外的生活

> 种一棵树最好的时间是十年前，其次是现在。

那么，现在就是最好的时间。
