## 纪律

- 四类口径分开标注：厂商标称 / 厂商实测 / 学术 / 标准原文。推导项（如「先裁 ROI 再滤波 ≠ 先滤波再裁 ROI」）在正文与图注双重标明为推断。
- **机型标签必须与原始数据文件核对后才写进图**。Zivid 基准数据的 105/424/12,653/7,102/4,294 属 Zivid 2 高配，7,182/24,980/343,978/14,150/41,593 属 Zivid 3 低配；初次转述曾把两组都标成「Zivid 2+」，经核对原始 JS 数据文件后更正。图注同时提醒：Zivid 2+ 高配的 Outlier 为负中位数（−257 µs），引用应写「可忽略不计」。
- 跨厂商并列时必须标注口径差异：Zivid 的「1500–3000 lux」是含机型例外的测试上限（规格支持页），Photoneo 的「100,000 lux」出自 2023 年 blog 帖（新闻稿），两者不对等，正文已说明。
- 曲线凡非实测数据点连线者，图注明确写「示意」。`s02` 的三条 ε_d 曲线为按公式计算的趋势，`s03` 的二次/一次对照为标度示意。
- 七个「未找到」项在正文明确列出，图上不出现替代数字：反射率可用性下限阈值、KEYENCE 的 accuracy 定义、Sony 的 3D 精度定义、VDA 5 正文定义、离群剔除的 ROC 曲线、下采样 wall-clock 与点数曲线、KD-tree 构建耗时标度。
- ISO 5725-1:2023 付费标准的原文经 ANSI preview PDF、ISO OBP 索引页与第三方镜像三处独立副本互证；iso.org 与 OBP 对自动抓取返回 403，此事实已在正文与本文件说明。
- 画成图的数据必须先在正文出现，遵守全局约定：先改正文，再改图。
