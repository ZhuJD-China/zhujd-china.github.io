## 真三维配图（`_src/`）

四张加粗的配图不是手绘 SVG，而是用 numpy 搭真三维几何、自己做透视投影渲染的：

- `_src/svg3d.py` —— 最小渲染器：相机模型、画家算法排序、深度雾化、沿视线方向的点云/球/有向长方体。
- `_src/fitcam.py` —— 取景辅助：给定场景包围盒与视口，二分搜索出能把全部元素框住的最小相机距离（手动调 `azim`/`elev` 比盲调参数稳）。
- `_src/g01_stereo.py` → `s12-stereo-3d.svg`
- `_src/g02_structured.py` → `s13-structured-light-3d.svg`
- `_src/g03_pointcloud.py` → `s14-pointcloud-filters-3d.svg`
- `_src/g04_lighting.py` → `s15-lighting-3d.svg`

依赖只有 numpy。运行方式（在仓库根目录）：

```
python images/3d-vision-2026/_src/g01_stereo.py
```

四张图均可**逐字节复现**（已验证：仓库内脚本重跑后 MD5 不变）。

### 数值纪律

- `g02` 的角偏差表用 ±1° 有限差分，并在脚本内用 `assert` 与解析灵敏度对账（`∂d/∂α`、`∂d/∂β`），容差取 4%（单侧差分的二阶截断误差）。早期版本有两处 bug：α 的分母未跟着 α 变、以及角度被重复转成弧度，都会让 β/α 比值算反。
- `g03` 的点云是**参数化几何面采样生成的合成数据，不是厂商实测数据**，图注已双重标明。三套滤波结果按 PCL/Open3D 的标准定义实算（`voxel_downsample` 取格内均值，`statistical_outlier` 取 k 近邻距离均值阈值），随机种子固定为 20260903。
- `g03` 的结论被实算数据**推翻过两次**，都记在这里以免回退：
  1. 初稿写「两种顺序差不多」。实算是面板 3 为面板 2 的**严格超集**（多 27 点），所以不能这么写。
  2. 改写后写「多了一整簇残留，全部落在 x < -100 一侧」。**这是错的**：那 27 点 x ∈ [-99.6, 96.1]，而 clean 的 |x| 上界是 90.8，两个面板在 x < -100 处都是 5 点，该指标根本不区分两路结果。真实的刻画是「27 点全部悬浮在表面外，到最近表面点距离中位 21 mm」，且来自三处不同的注入簇（弥散 17 / 左侧带 9 / 右前团 1）。
  3. 最终落点：**差异只有 0.65 %、质心只差 0.18 mm，但方向确定**（先降采样是严格超集）。质心污染的成因是**离群没剔干净**（900 个注入点只挡下 280 个），不是顺序——原文「顺序错了就全错」的说法据此改写。
- `g03` 的注入离群点是三簇（320 / 300 / 280），不是两簇；写正文时按 `_src` 里的实际代码核对过一次，见上文第 2 条。

## 纪律

- 四类口径分开标注：厂商标称 / 厂商实测 / 学术 / 标准原文。推导项（如「先裁 ROI 再滤波 ≠ 先滤波再裁 ROI」）在正文与图注双重标明为推断。
- **机型标签必须与原始数据文件核对后才写进图**。Zivid 基准数据的 105/424/12,653/7,102/4,294 属 Zivid 2 高配，7,182/24,980/343,978/14,150/41,593 属 Zivid 3 低配；初次转述曾把两组都标成「Zivid 2+」，经核对原始 JS 数据文件后更正。图注同时提醒：Zivid 2+ 高配的 Outlier 为负中位数（−257 µs），引用应写「可忽略不计」。
- 跨厂商并列时必须标注口径差异：Zivid 的「1500–3000 lux」是含机型例外的测试上限（规格支持页），Photoneo 的「100,000 lux」出自 2023 年 blog 帖（新闻稿），两者不对等，正文已说明。
- 曲线凡非实测数据点连线者，图注明确写「示意」。`s02` 的三条 ε_d 曲线为按公式计算的趋势，`s03` 的二次/一次对照为标度示意。
- 七个「未找到」项在正文明确列出，图上不出现替代数字：反射率可用性下限阈值、KEYENCE 的 accuracy 定义、Sony 的 3D 精度定义、VDA 5 正文定义、离群剔除的 ROC 曲线、下采样 wall-clock 与点数曲线、KD-tree 构建耗时标度。
- ISO 5725-1:2023 付费标准的原文经 ANSI preview PDF、ISO OBP 索引页与第三方镜像三处独立副本互证；iso.org 与 OBP 对自动抓取返回 403，此事实已在正文与本文件说明。
- 画成图的数据必须先在正文出现，遵守全局约定：先改正文，再改图。
