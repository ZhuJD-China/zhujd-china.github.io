## 纪律

- 数值一律标注口径：厂商标称 / 厂商实测 / 学术报告 / 标准 / 本节推导。推导项（如格距误差 1:1 传递）在图注与正文双重标明。
- 曲线的「示意形态重绘」与「按实测数据绘制」分开表述。凡重绘的曲线（如远心三镜头对比、MTF 曲线、寿命衰减曲线），图注明确写「形态为示意，不按实测数据点连线」。
- 跨厂商比较一律先对齐口径：畸变波长（@588 nm / @520 nm / Inf.）、景深判据（20%@20 lp/mm / 像元 3.45–5.5 µm / CoC 2–4 px / CoC 40 µm）、Airy 斑基准波长（550 / 588 / 632.8 nm）。图上不混用不同口径的数字。
- 三个「未找到」项在图中显式排除，未用替代数字冒充：机器视觉 LED 均匀性的统一数值、Schneider/OPT 的标定板精度对照表、「气压 0.01%/10 kPa 焦距漂移」。
- 画成图的数据必须先在正文出现，遵守全局约定：先改正文，再改图。
