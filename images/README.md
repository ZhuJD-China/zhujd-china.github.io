# 博客配图目录

站点正文中的插图统一放在本目录下，按文章归档，一文一夹，与文章文件并列于 Git 版本管理。

## 目录约定

```
images/
  README.md               本文件
  zhijia-2026/            《国产智驾大横评：七家车企的技术路线与量产口径》配图
    README.md             该文配图清单、数据口径与更新记录
    s01-*.svg ~ s06-*.svg 正文插图，s 前缀数字对应文中出现顺序
```

## 规则

1. **一文一夹**：夹名取文章 slug（ASCII 小写加连字符），不使用中文路径，避免 URL 编码问题。
2. **顺序前缀**：文件名以 `sNN-` 开头，NN 为两位序号，与文章中插图的出现顺序一致，便于插图与正文同步增删。
3. **格式**：统一使用 SVG。理由是可无限缩放、文件体积小、文本可检索、无版权与画质损失，浏览器在 `<img>` 中可直接渲染。
4. **主题**：站点默认深色主题，配图统一按深色底（`#0b0b10`）与站点色板绘制，在浅色主题下呈现为深色图版，属预期效果。
5. **色板**：与 `assets/style.css` 的 `:root` 变量保持一致。

   | 用途 | 色值 |
   | --- | --- |
   | 背景 | `#0b0b10` |
   | 正文 | `#e8e4dc` |
   | 次要文字 | `#a09b8d` |
   | 弱化文字 | `#6b675c` |
   | 强调（官方口径） | `#c9a96a` |
   | 警示 / 高阶档位 | `#cf5a50` |
   | 第三方方案 | `#7aa2c8` |

6. **重绘论文图**：arXiv 论文多为非独占许可，不授权把原图再发布到博客。因此凡引用论文插图，一律**按原图结构重绘**（结构、数值、图号一一对应），并在图注中标注「重绘自 arXiv:编号 原文图 N」，供读者点回原文核对。这样既合规，视觉风格也统一。
7. **引用方式**：正文使用相对路径（站点页面位于根目录，故路径自根起算）。

   ```markdown
   ![图注文字](images/zhijia-2026/s01-xxx.svg)
   ```

8. **数据纪律**：图中每个数字必须在对应文章的正文里出现过，且带口径标注（官方 / 二手 / 未核实）。改数据先改正文，再改图，避免图文脱节。
