## 纪律

- 规格一律区分「厂商标称」与「EMVA 1288 实测」，不采用营销页上的对比性表述。
- 带宽、距离、帧率必须标注是标准上限、理论值还是实测。
- 引用的每个型号参数都取自厂商官方产品页或 datasheet，不用经销商或聚合页面。
- 画成图的数据必须先在正文出现，遵守全局约定：先改正文，再改图。
